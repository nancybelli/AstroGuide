# AstraSky Astrology Platform

A single-page, responsive web application featuring free birth chart calculations, localized daily horoscopes, a built-in email lead-capture engine, and premium report up-sells based on Linda Goodman's Sun-Sign compatibility frameworks.

## Features
- **Free Birth Chart Calculator:** Instantly calculates the user's Core Triad (Sun, Moon, and Rising signs).
- **Daily Horoscope Engine:** Dynamically generates a strategic daily outlook based on the chosen zodiac sign.
- **Lead Capture Wall:** Seamlessly locks free tool results until the user inputs their email address to build your marketing database.
- **Premium Shop Interface:** Built-in hooks for monetizing deep-dive planetary progression and synastry reports.

## Tech Stack
- Frontend: HTML5, CSS3 (Custom Properties, CSS Grid, Flexbox)
- Logic: Client-side JavaScript
